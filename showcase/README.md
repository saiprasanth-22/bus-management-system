# Hosted Showcase

This folder contains a **presentation-only web frontend** for the Bus Management System.

It exists so the project can be demonstrated as a polished Modern Transit interface on Vercel.

## Important boundary

The hosted interface uses HTML, CSS and vanilla JavaScript for presentation and interaction. These files are **not part of the NCERT-constrained executable Informatics Practices submission**.

The syllabus-scoped project logic remains in:

- `src/` — Pandas and Matplotlib examples
- `sql/` — MySQL schema and queries
- `data/` — fictional CSV records
- `docs/NCERT_METHODS.md` — method whitelist

This separation prevents presentation technology from being confused with the code the student is expected to explain in a viva.

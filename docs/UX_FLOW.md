# UX Flow — Modern Transit

## Landing page

Primary actions:

```text
[ STUDENT PORTAL ]   [ FACULTY PORTAL ]

         [ PLATFORM TOUR ]
```

A compact metro-line motif acts as the visual signature of the product.

## Platform tour

### 1. Welcome

Message:
> A transport management platform for students from Classes I-XII.

Visual:
```text
SCHOOL ●────●────●────●
       BUS  ROUTE STOP STUDENT
```

### 2. Connected network

```text
          ROUTE
         /     \
       BUS     STOP
         \     /
         STUDENT
```

Explain that students are associated with existing buses, routes and boarding stops.

### 3. Student portal

The student view behaves like a transport pass.

Show:

- Student ID
- Student name
- Class and section
- Bus number
- Route
- Boarding stop
- Distance
- Transport fee
- Fee status

Avoid admin controls and unnecessary charts.

### 4. Faculty portal

Navigation:

```text
Dashboard
Students
Buses
Routes
Stops
Reports
```

Dashboard information:

- total students using transport
- total buses
- total routes
- total stops
- bus-wise strength
- class-wise usage
- selected record table

### 5. Reports

Report set:

- Bus-wise Student Strength
- Class-wise Transport Usage
- Route-wise Student Strength
- Distance vs Transport Fee

Final actions:

```text
[ ENTER STUDENT PORTAL ]
[ ENTER FACULTY PORTAL ]
[ RETURN HOME ]
```

## Visual rules

### Palette direction

- background: off-white/light grey
- primary: transit blue
- success: green/teal
- highlight: amber
- warning/error: red
- text: dark navy
- route colours may vary by route

### Shape language

- thin transport lines
- circular route nodes
- restrained rounded cards
- minimal shadows
- simple outline/glyph icons
- no fantasy, cyberpunk, glassmorphism or oversized decorative effects

### UX rule

Student screens stay simple.

Faculty screens may be information-dense, but every block must support an actual transport-management task.
